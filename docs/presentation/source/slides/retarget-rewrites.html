The core problem: Vulkan has logical addressing. A shader may not do pointer arithmetic.

Mojo and MAX on Adreno · 5

This table is the whole job of the retargeter. Mojo kernels look like CUDA: they take raw pointers and scalars as arguments and compute addresses freely. A Vulkan compute shader takes no arguments at all. Memory arrives through descriptor-bound storage buffers, and SPIR-V for Vulkan uses logical addressing, which means a shader cannot do arithmetic on pointers. So every pointer argument becomes a storage buffer at a fixed binding, every scalar argument becomes a 64-bit slot in a small parameter buffer, and every address is tracked through its chain of getelementptr instructions as a pair: which buffer, and which element index. At each load or store we rebuild a typed access into that buffer. AMD-specific pieces get translated too: thread and block registers become SPIR-V builtins, AMD’s lane-permute instructions become subgroup shuffles, the barrier becomes OpControlBarrier, and for Qualcomm’s stock driver, which has no 64-bit integers, all index math is narrowed to 32 bits.
