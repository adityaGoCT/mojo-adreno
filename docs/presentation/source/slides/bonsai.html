Mojo and MAX on Adreno · 25 · bonsai/ · kernels: mav3ri3k/modular · decode: Galaxy S26 Ultra · prefill: Qualcomm’s SM8850 reference phone

A second model, and a different kind of test. Bonsai 2 2B is PrismML’s ternary model: every weight is minus one, zero or one, stored in two bits, and it mixes 18 gated DeltaNet layers, a recurrent state instead of a growing cache, with 6 ordinary attention layers. Another developer had already ported it to this same Adreno 840, in their own fork of Modular’s repository, with a new OpenCL target. Their GPU kernels are plain Mojo. So instead of writing our own, we took their kernel file as it is and compiled it with our Vulkan target. All 21 kernels it uses compiled and validated without changing a line: two-bit unpacking, fp16 multiply-adds in vectors of eight, the 64-lane shuffles of the Hadamard transforms. What we did write is the runtime: their forward pass and weight loader, translated into about 550 lines of C on Vulkan, 721 dispatches a token recorded once. On the phone it generates 80 tokens a second, 12.4 milliseconds a token, and for 16 steps every greedy token matches the exporter’s FP32 reference, with all 248 thousand logits compared at every step. Their own OpenCL build reports about 75 tokens a second on a regular S26; that is a different phone and short runs, so not a race, but it shows the kernels lose nothing by going through SPIR-V and Vulkan. The point: Mojo kernels are portable across GPU APIs; what each port has to write is the runtime around them. Then the prompt. Run token by token, a 412-token prompt takes 5.2 seconds. For batched prefill we reused their kernels a second time: a thin wrapper offsets each prompt row’s pointers and calls the decode kernel, so one dispatch covers every row, for the norms, the Hadamard transforms, the gates, RoPE, the KV cache and attention values. What is new is three kernels. Every ternary projection becomes one matrix product over all the rows on cooperative matrices, the two-bit codes unpacked into fp32 in shared memory as they are staged; the attention scores are matrix products too; and the DeltaNet recurrence, which is sequential by nature, runs as one scan with each thread’s slice of the state in registers. On Qualcomm’s own SM8850 reference phone the prompt takes 0.87 seconds, six times faster, and the 16 checked tokens still match the FP32 reference. Nine tenths of that time is the matrix products, at about 1.8 teraflops in fp32.
