Mojo and MAX on Adreno · 12

So where did MAX stop? Four walls. First, there was no code generator for this GPU: the Mojo compiler linked LLVM’s NVIDIA, AMD and Apple backends, and no SPIR-V. Second, MAX’s runtime came as wheels for macOS and Linux hosts, with device backends for CUDA, HIP and Metal, and nothing for Vulkan, OpenCL or Android. Third, the shipped compiler is a closed binary: it would not dump its internal MLIR, so the earliest point we could grab a kernel was the LLVM IR, after Mojo had already committed to an AMD target. Fourth, even if we could reach the phone, MAX’s optimized library kernels are written around NVIDIA tensor cores, AMD matrix cores and asynchronous copies, which have no Vulkan equivalent on this GPU. That is why act two used our own 398-line Vulkan program instead of MAX, and why every kernel went through the retargeter. Then the situation changed.
