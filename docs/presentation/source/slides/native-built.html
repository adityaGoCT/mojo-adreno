Mojo and MAX on Adreno · 14 · code: adityaGoCT/modular, branch adreno-spirv-target · built with Bazel on an M4 Mac

So we built the compiler from source and gave it a real target called adreno710. It took three pieces. In the compiler, about 1,250 lines of C++: the target’s identity, which tells the compiler a Vulkan SPIR-V triple is a GPU; a lowering hook that marks kernel entry points; and a backend. Most of the backend is one 840-line LLVM pass that does in-process, with full type information, what our Python retargeter did on text: it turns pointer arguments into storage buffers and scalars into a parameter buffer, and rebuilds every address as a buffer and element index. Second, two Mojo plugins, using the extension points we just saw: the standard-library plugin reads thread and block indices from SPIR-V builtins and maps exp, sqrt and friends to native GLSL instructions; the MAX plugin sets 64-lane warps, the barrier and shuffles. Third, one small addition to MAX: a hook that lets a target implement a whole-warp sum natively. The result is one command, and out comes a SPIR-V binary per kernel.
