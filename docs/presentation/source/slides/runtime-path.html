So what would it take to really run MAX on the phone? Four pieces. First, a Vulkan driver plugin. MAX defines a C interface for new devices, 61 functions covering devices, memory, queues, events and loading kernels; the CUDA, HIP and Metal plugins in the repository are about 2,500 lines each, and our 398-line Llama runtime already does a Vulkan subset of the same job. Second, the runtime libraries have to be built for Android; today the build has no Android toolchain at all. Third, the phone should not run the compiler. MAX can save a compiled model, so the realistic flow is to compile on the Mac for adreno710 and ship the result. Fourth, every operation a model uses has to compile for this target and then be tuned, which is open-ended. Items one and two are weeks of engineering; item four is what the compile test measures, and it is where Modular’s own vendor-specific kernels will need generic or Adreno-specific versions.
