The matrix units are reached through cooperative matrices: a tile that a whole subgroup loads, multiplies and stores together, while the driver decides which thread holds which element. In Mojo this is a small type, CoopMatrix, with zero, load, multiply-add, cast and store, and the loop on the slide is a complete matrix multiply. Each operation is a marker call; our ABI pass, which already knows which buffer every pointer reaches, rewrites the markers into SPIR-V cooperative-matrix instructions with the right types. On the S26 Ultra, with tiles staged through shared memory, a 2048-cubed multiply runs at 3.7 teraflops in fp16 and 2.5 in fp32. Remember the driver: the fp16 product also sums in fp16, so for long sums we will use fp32 tiles at two thirds of the speed. MAX’s own matmul kernel now takes this path on adreno840 for fp16 and fp32 shapes in multiples of 64: its three test graphs pass on the phone, the fp16 one eight times faster than MAX’s naive kernel.
