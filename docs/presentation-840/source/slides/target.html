Mojo on the Adreno 840 · 3 · Mojo built from source · adityaGoCT/modular, branch adreno-spirv-target

Mojo’s compiler has been open source since August, so we built it from source and added a target. A Mojo GPU kernel is written exactly as for NVIDIA or AMD. With the flag --target-accelerator adreno840, our target plugins decide what a thread index, a barrier, a warp operation or a matrix tile becomes for this GPU, with 64-lane subgroups. Mojo’s own optimizer runs as usual. Then a Vulkan ABI pass reshapes each kernel into a Vulkan entry point: every pointer argument becomes the next storage buffer, every scalar argument a 64-bit slot of one params buffer, and cooperative-matrix operations get their matrix types. LLVM’s SPIR-V backend, which we patched so Vulkan shaders may use matrix instructions, writes SPIR-V 1.6. What does not exist is MAX’s runtime for Android. So each model here has a small C runner: it loads the weights, creates the pipelines, records every dispatch of a token into one command buffer, and checks the output.
