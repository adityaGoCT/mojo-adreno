Snapdragon X2 Elite X2E88100 · Windows 11 on Arm · 33.6 GB · Qualcomm Device Cloud, driven from a Mac

This is Qwen’s Qwen3-30B-A3B, a mixture-of-experts model: 30.5 billion parameters in 48 layers, each with 128 experts of which a router picks 8 per token, so a token uses 3.3 billion. It runs in int4 on the Adreno X2-90 GPU of a Snapdragon X2 Elite laptop in Qualcomm Device Cloud. The forward pass is Mojo DeviceContext code, the same way SmolVLA and π0 run on that laptop: the program runs on a Mac and drives the laptop’s Vulkan server through our driver plugin. It decodes at 31 to 37 tokens a second. The whole model is 15.75 gigabytes on the GPU, which had to fit inside the GPU’s one 16.8 gigabyte heap. A 404-token prompt is read in 4.31 seconds, 2.8 times faster than a token at a time. And the GPU’s logits are within 1e-4 of transformers’ own Qwen3-MoE layers running on the same weights. The last part of the talk puts one of its layers on the laptop’s Hexagon NPU.
